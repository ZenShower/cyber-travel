# Links 摄影

本 Skill 的目标不是复制山、雾或特定时刻，而是把一位摄影者**身在现场、克制观察、顺着真实光线发现秩序**的能力转移到新场景。开始时看 [文字图谱](references/reference-atlas.md)。可选的自有摄影图板可以放在 assets/reference-board.jpg；没有图板时直接依据文字作摄影判断。不要假定图谱中的场景就是本次地点。

## 核心语法

对每张图决定以下六件事，而不是叠加形容词：

1. **站在哪里**：明确摄影者可抵达的机位、高度与观察距离。像现场照片，避免无缘由的上帝视角、极端广角或宣传照正面机位。
2. **画面如何被读懂**：选择一条主路径或主形状，并安排前中远景、遮挡、大小对照与留白。画面可以宏大，也可以只有窗影、冰纹、树枝等局部。
3. **什么证明时间正在流动**：人的背影或动作、脚印、车辆与建筑的使用痕迹、正在变的光、风雨雪或水流。只取一两个，不摆拍完整剧情。
4. **光实际从哪里来**：天光、太阳、窗、道路灯或室内实用灯。以光源决定亮暗与阴影；空气透视来自距离与天气，不用统一发灰滤镜。
5. **颜色从什么物质来**：由场景的真实材质、天气和光决定主色，再选一个自然存在的小面积对位色。允许明亮雪地、暖日落、浓蓝夜色、鲜红秋叶、温暖木室；不强制冷色或低饱和。
6. **细节怎样克制**：保持亮部连续、暗部有可感材质、局部色彩分离和细节清晰；不使用全面锐化、HDR 光晕、假胶片磨损、漫射柔焦或超现实完美表面。

这些规则是共同能力，不是画面元素清单。新场景里没有人的话，可用人留下的痕迹或纯粹的光、材质与几何完成照片。场景没有自然光时，就观察其真实可用的灯光。

## 使用参考图片时

用户提供的参考图只负责视觉能力；新地点的地貌、建筑、天气和人物安排仍由当前任务决定。优先级是：**用户指定事实与限制 → 核实过的地点特征 → 本组连续性 → 每张参考图指定的抽象作用 → 相机名称**。选 2–3 张参考时，可按用户要求随机抽取并记录编号；为每张指定**一项抽象作用**，例如空间尺度、空气层次、明暗重量或静态停顿，同时明说其具体物件不应迁入新场景。仅在用户要求对照或需要验证图参效果时，另做纯文字基线并分开保存；正常成图直接使用选定的方案。图参版尤其检查是否出现了参考图里的雪、瀑布、室内物件、非本地山形，或把原参考的机位照搬到每一张。

## 一组图的编排

先从用户的新场景提取**场景指纹**：可见的空间结构、三种最有辨识度的材质、实际光源、正在发生的一件小事、一个可选的人类痕迹。具名真实地点先核对辨识性地貌与建筑，不用生成图反过来证明地点事实。地点、季节和时段由用户定；没给定时只做有助于成图的合理假设，并保持整组一致。不从参考图自动移植雪山、雾、雨衣、旅行车或某个国家。

为一组图提出 4–6 个不同的观察位置与距离，通常包含：

- **空间**：交代新场景的几何、深度和环境尺度。
- **关系**：一个人、物或痕迹如何与空间发生联系。
- **细节**：一种能感到温度、湿度、磨损或运动的材质。
- **停顿**：没有强事件的一角、入口、室内或离开后的余迹。

这四种功能可以调整数量和顺序，不必每组都有人，也不必每张都宽幅。固定同一场景指纹与摄影态度，让机位、远近、主路径、局部色彩发生变化。若用户指定比例或张数，以用户为准。提供系列时，先给简短拍摄方案，再逐张制作；只要求图片时直接交付图，不用额外铺陈。

## 哈苏设定与成像

按用户要求，以 Hasselblad X2D 系列数字中画幅为创作中的相机设定。追求宽容而自然的明暗过渡、稳定但不僵硬的颜色、真实材质的细微层次。为每张选择合理的广视角、标准视角或较窄视角；近处和远处通常都能辨认，只有物理理由明确时才用浅景深。真实拍摄方案可建议 XCD 38V、55V、90V 这类焦段和适合现场的曝光，但不把型号或参数当成生图咒语。AI 图不能冒充有真实哈苏 EXIF 的实拍照片。

## 执行与检验

每张提示词按 `可观察场景 → 机位与阅读路径 → 人/痕迹/瞬间 → 光源与空气 → 材质与颜色 → 哈苏成像取向 → 场景特有错误约束` 组织。使用图像生成工具时，若用户要成图就实际生成并目视检查；若只要提示词或分析，只交付文字。参考图用于提炼能力，不默认逐像素复刻。

验收时先在缩略图中问：**不看地名、不看相机名，这组图是否仍像同一个摄影者在同一场景里的观察？** 同时问：**遮住标题后，能否看出每张有不同的观看距离或画面任务？** 再逐张看：空间是否可信；主视觉关系是否清楚；光线与阴影有无来源；亮暗是否有层次；人物与使用痕迹是否自然；参考图是否带入错误的地点物件。发现失败时，只改最影响结果的一项，重新出图并复核。记录实际失败，才将个别经验升级为通用规则。

若后续画面重复参考首张的正面机位，改写摄影者的**位置、朝向、机位高度和主体在画面中的尺度**，而不只是换一个人物或裁切。地标图可以有一张全貌，其余应贡献不同的观看距离与功能。
