# 参考图谱：观察结果与可迁移能力

以下 11 组观察关系用于构图与摄影判断。公共版只分发文字图谱，不包含原始用户截图或摄影作品。若自行添加图板，只提取空间、光线和颜色关系，不移植具体地貌和人物。

| 图 | 可见决定性关系 | 底层能力，而非可复制道具 |
| --- | --- | --- |
| 01 | 雾中绿色峡谷、双层瀑布、斜坡花带、极小的两人 | 多层地形用一条斜线组织；人物给空间定尺度；雾创造深度 |
| 02 | 大片有细微起伏的亮雪，脚印通往远处登山者和山体 | 用连续行动痕迹连接不同尺度；在高亮区域留纹理 |
| 03 | 暖色余晖铺满天空与水面，暗岩岸与小屋压住下沿 | 让时刻成为事件；亮部与深色前景保持重量平衡 |
| 04 | 蓝调雪山和湾区围住小镇，路灯形成暖色路径 | 环境主色与生活光构成小面积对位；道路描述地理结构 |
| 05 | 蓝色水域、冰纹和雪岸的抽象切分 | 无人物、无地标仍可成立：直接观察材质与形状 |
| 06 | 雪山、低云、花树、草和河流组成前后层次 | 用附近的季节信息重新观看远处地标 |
| 07 | 红叶压住上沿，雪山、湖岸、车和游客依次后退 | 容纳日常旅行痕迹；用近景框架与远景形成深度 |
| 08 | 一个黄雨衣背影站在浓雾和绵密苔藓中 | 人物正在观察而非表演；单个色点保持视觉重心 |
| 09 | 极深暗坡与蓝天之间立着尖峰，城镇灯光散落谷底 | 敢于保留暗区；以少量真实亮点维护空间尺度 |

| 11 | 仰拍林木，逆光中有雪粒运动，局部略柔 | 看见天气正在发生；柔和来自逆光与运动，不是通用滤镜 |

## 抽象出的六项能力

1. **可信的在场机位**：画面像有人从可抵达的位置举起相机，而非无人机或广告摄影棚的万能视角。可以高、低、远、近，但摄影者与场景有可理解的关系。
2. **清楚的空间秩序**：通常存在一个主形状或主路径，再用前中远景、大小关系、遮挡和留白建立阅读顺序。不追求每处都成为焦点。
3. **环境自身发生的瞬间**：脚印、雨衣的停顿、城镇开灯、光穿过窗、雪粒飘落。叙事轻，不让人物进行夸张表演。
4. **自然光与空气塑形**：雾、云、窗、日照、蓝调或灯光各有可解释的来源和方向。空气感来自距离、天气与曝光，不靠泛白蒙层。
5. **分离但不套色的色彩**：每张从地点实际物质和时刻生成主色；常由小面积反色或暖冷差稳住画面。可冷可暖、可艳可淡，拒绝统一 LUT。
6. **中画幅式的质地与克制**：细节清楚但不硬，亮部过渡平顺，暗部保有层次；局部柔和可由镜头、运动或空气解释。没有全局 HDR、假胶片划痕或荧光饱和。

## 差异同样重要

图 01、08 都有雾，但一张看巨大落差、一张看近身停顿；图 03 是暖日落，04、09 是蓝调；02、06、07 的颜色较亮；05、11 以材质和天气细节取代宏大风景；07、10 容纳车、游客与房间。故这个风格不能被简化成“孤独人影 + 冷色群山 + 雾”。

## 迁移反例

- 新场景是车站，就不照搬瀑布、雪山、黄色雨衣。寻找可真实存在的月台线、候车距离、玻璃反射、自然或实用照明。
- 新场景是厨房，就不强加远景山脉。用台面、窗、门洞、动作残留、材质和静止片刻建立同样的观察关系。
- 不给每张图塞一个人：05、10、11 证明空镜和细节同样是系列的一部分。
