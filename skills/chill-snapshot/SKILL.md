# Chill 随意拍

目标是让照片像拍摄者在生活里被某个瞬间吸引，顺手举起相机拍到。画面可以漂亮，但不需要每个主体都端正、每处光线都均匀、每一层都清楚。它的气质来自**在场、亲近、松弛和判断自信**，不是刻意把照片做旧或做坏。

这套能力独立于 Links 摄影。用户指定设备、地点、人物、原图保留项时以这些条件为准；未指定相机时不强加品牌或中画幅质感。若用户明确要求 Links 风格或专业摄影创作，应使用相应 Skill。

## 先找到值得按快门的一秒

面对场景，先确定拍摄者与主体的实际关系：是在路边走过、与朋友同行、隔着车窗、坐在室内，还是被眼前一处光吸引？选择一个可感的瞬间，例如人刚回头、风掀起衣角、雨滴滑过玻璃、车经过画面边缘。允许拍在事件将起或刚结束时，避免人人都准备好面对镜头。

给每张照片留一个**可读的锚点**：动作、表情、颜色、光斑或空间关系。其他部分可以被遮挡、虚化或切出画外。随意的构图仍要能看出拍摄者当时注意了什么。

## 真实感先来自场景本身

- **空间有前后**：用现场已有的遮挡、大小变化、受光差异或远处较低的对比建立距离。只选当前画面需要的关系；没有雾、烟、水汽等介质时，不凭空添加体积光或雾蒙蒙的远景。空气中的光束还需要可辨的光源和方向。
- **材质有接触史**：细节附着在具体物体上，并随形体、受力和光变化。衣服的褶皱顺着动作形成，水滴贴着玻璃流动，指纹出现在被触碰的位置，灰尘积在边缘或缝隙；皮肤保留自然色差、发丝与微小纹理。按镜头距离取可见的少数证据，不给全画面盖一层“真实纹理”。
- **光与颜色属于现场**：窗、天空、路灯、店灯和附近墙面的反射决定阴影方向、软硬与局部色偏。阴影里可以保留噪声，室内可以有不完全中性的白平衡；也允许现场本来鲜艳的颜色。不要预设统一灰调或电影调色。
- **清晰度有层次**：焦点所在平面可比边缘、前景和背景更实；运动、景深与光学边缘衰减各有不同形态。保住画面锚点或主体关系即可，不要求每个局部都锐利，也不要用算法锐化和涂抹式降噪抹平材质。

这些原则吸收了 [AI Cinematic Prompt](https://github.com/Leo414x/AI_Cinematic_Prompt/blob/main/SKILL.md) 对空间与光的物理约束，以及 [realistic-image](https://github.com/jax-explorer/sjinn-professional-skills/blob/main/skills/realistic/realistic-image/SKILL.md) 对未修饰材质和真实镜头行为的要求；不沿用前者的电影预设、胶片影调或固定提示词层级，也不沿用后者的棚拍人像、纯背景与统一近景构图。

## 七种可选择的现场成像机制

根据光源、运动、设备和机位，选最有解释力的少数机制。可以一项都不用；同组照片不要重复叠加相同缺陷。若同一画面已有明显浅景深、雨雾或动态模糊，就收住其他柔化效果，让不同虚实层仍有清楚的结构。

1. **不完美的曝光**：明确测光优先照顾人脸、窗外、灯牌还是阴影中的动作。强窗光可局部过曝，夜间可让暗部沉没，逆光人像可保留脸部偏暗；不要把每块亮暗平均修回。
2. **柔光**：阴天、雨雾、薄云、墙面反射或窗帘让阴影边界自然变软。若使用镜头前的薄雾、水汽或逆光眩光，效果应局限在相关光区；避免全图统一发光。
3. **虚化与对焦偏差**：说明焦点原本落在哪里。近摄、大光圈或前景遮挡可形成景深虚化；仓促抓拍可让焦点稍落在背景或前景，主体仍有足够轮廓可辨。焦外景物保持连贯的形体与尺度，不变成涂抹色块；不要把光学景深、失焦和整张低分辨率混为一谈。
4. **动态模糊**：由主体运动、手持移动、慢快门或追随拍摄引起。拖影应有方向与局部差异：走动的手臂模糊而躯干尚可辨，追拍车辆时车相对稳定、街景横向拉开。
5. **果冻效应**：仅在电子快门逐行读取且快速运动或快速转动相机时考虑轻微形变。它与普通动态模糊不同；静态建筑、山景或使用镜间／全局快门的画面不要添加。
6. **高 ISO 噪点**：弱光中为了保住快门速度而提高感光度时，暗部可能出现细微数字噪声和轻微色彩不稳定。亮部与暗部程度不同；不把均匀胶片颗粒当成所有照片的真实感来源。
7. **随意而自信的构图**：允许主体偏边、近景挡住一角、地平线略偏、人物出画、留白不平均或临时举机的角度。取舍要服务当下注意力和人物关系，不能靠随机歪斜制造“随手感”。

这些机制之间要符合物理关系。大白天的高速快门通常无需明显高 ISO 噪点；柔和阴天也不自动带来失焦；果冻效应需要电子快门和快速运动。为每种偏差写出产生它的现场原因，而非只列风格词。

## 创作与提示词

组织顺序：`现场中发生什么 → 拍摄者站在哪里／为何举机 → 画面锚点与临时取景 → 一种有用的前后空间关系 → 实际光源与测光取舍 → 贴合主体的材质证据 → 焦点、运动、噪点等有因的成像表现 → 需要保留的场景事实`。不必每项都写满，优先用观察句描述可见结果，少用“cinematic、35mm film grain、perfect composition”等泛化标签。

若输入是照片，先识别不可改的人物、地点、关系和主动作，再决定是否只改变成像气质，或按用户许可重构取景。不要为制造随意感而更换人物身份、增添剧情或抹掉原图关键内容。若用户要求系列，让镜头距离、拍摄者与人的关系、注意力落点自然变化；整组无需统一缺陷强度。

例如：

- 傍晚同行时回头拍朋友：人靠画面一侧，街边行人与店面尺度逐层退远；远处店灯有小块溢出，转身的手稍有拖影，衣袖折痕顺动作受力，脸和街道关系仍可读。
- 雨后从公交车窗望向街口：焦点偶然落在玻璃水滴上，水痕沿窗面下滑，行人略软而轮廓连贯，路灯反射被水痕局部拉长；不额外添加全屏雾化。

用户要成图时实际生成并目视检查；只要分析或提示词时提供对应文字。验收先问：这张照片像是有人因眼前事物而按下快门吗？锚点是否清楚？空间距离、光源、材质痕迹是否彼此吻合？每一处曝光、模糊、噪点或形变是否有可说出的原因？如果缺陷成为第一眼看到的内容，或多种柔化让画面失去结构，就减少它。只有经过具体试作验证的修正，才升级为固定规则。
